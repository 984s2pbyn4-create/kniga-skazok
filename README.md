# Книга сказок

Веб-приложение, которое открывает любую книгу в виде старинной книги сказок: кожаный переплёт, пергаментные страницы, буквицы, заставки и концовки глав, 3D-перелистывание, музыка шкатулки и треск камина. Книга выводится через проектор на стену или потолок. Подходит и детям, и взрослым.

Версия: 1.4

## Возможности

- Форматы книг: fb2, fb2.zip, epub, txt. Картинки из fb2 и epub показываются на страницах.
- Детская полка: 10 русских народных сказок с иллюстрациями (Репка, Колобок, Курочка Ряба, Теремок, Маша и медведь, Три медведя, Лиса и журавль, Заюшкина избушка, Гуси-лебеди, Петушок — золотой гребешок), сборник «Сказки для малышей» и «Сказка о Пирожочке и сонной Луне».
- Озвучка: чтение вслух голосом iPhone/iPad (выбор голоса, скорость, высота) с подсветкой абзаца и автоперелистыванием, а также запись своего голоса для каждой страницы.
- Режим проектора: поворот 0/90/180/270°, отражение, коррекция наклона, размер и яркость.
- Автоперелистывание и таймер сна.
- Звук: генерируемая мелодия шкатулки, своя музыка, камин, шелест страниц.
- Запоминает страницу и хранит 6 последних книг прямо в браузере.
- Управление касанием, свайпом, кнопками или Bluetooth-пультом (стрелки и PageUp/PageDown).

## Файлы

- `index.html` — всё приложение в одном файле.
- `manifest.webmanifest` — установка на экран «Домой».
- `icons/` — иконки приложения.

## Публикация на GitHub Pages

1. Загрузите файлы в репозиторий, сохранив папку `icons`.
2. Откройте **Settings → Pages**, в **Source** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, нажмите **Save**.
3. Через минуту-две приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

Для работы нужен интернет при первом открытии: шрифты загружаются с Google Fonts, а библиотека JSZip (для epub и архивов) — с cdnjs.
